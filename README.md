# URL Manager Browser Extension

[![Chrome Web Store](https://img.shields.io/badge/Chrome-Extension-blue?logo=googlechrome)](https://chromewebstore.google.com/detail/url-manager/emdblfmcdnifjcldbajedjbfjhmbkopp?authuser=0&hl=en)
[![Version](https://img.shields.io/badge/version-2.1.0-green.svg)](https://github.com/yourusername/url-manager)

A lightweight and intuitive browser extension designed to help you manage and organize your frequently used links effortlessly. Perfect for job seekers, researchers, developers, and anyone who needs quick access to important URLs.

## 🚀 Purpose

URL Manager is the perfect companion for users who want a convenient way to store and access frequently used links. Whether you're a job seeker managing applications and resources, a developer bookmarking documentation, or a researcher organizing references, URL Manager keeps everything at your fingertips.

---

## ✨ Features

### Core Features
- **📝 Add New Links:** Quickly save links with descriptive titles
- **✏️ Edit Saved Links:** Update link details anytime
- **🗑️ Delete Links:** Remove unwanted entries with one click
- **📋 Copy Links:** Instant clipboard copy functionality
- **🔄 Duplicate Links:** Create copies of existing entries
- **↕️ Drag & Drop Reordering:** Organize links by dragging them into your preferred order
- **🔍 Smart Search:** Find links instantly with real-time search
  - Highlights matching text in note titles
  - Visual indicator for matched links
  - Debounced and throttled for optimal performance
- **📜 Smooth Scrolling:** Vertical scroll support for large collections

### User Experience
- Clean, modern interface
- Responsive design
- Hover tooltips for all actions
- Visual feedback for all interactions
- Persistent storage across sessions
